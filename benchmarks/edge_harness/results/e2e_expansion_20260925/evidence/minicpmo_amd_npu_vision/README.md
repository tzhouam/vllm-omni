A later KV-projection cut passed three-image resampler parity and a scoped three-image complete Omni image-to-text+speech suite with verified AMD NPU execution; the route remains experimental.** The real checkpoint at revision `503e754207c94da6bb26850b4469f367c9ea3582` supplied a BF16 SigLIP vision transformer. It isolates a vision encoder block after patch/position embedding and before post-layernorm, so image preprocessing, resampling, the thinker, speech head and vocoder are outside the measured graph.

### One complete Omni image-to-text+speech request with the NPU KV cut

The [opt-in stage-0 adapter](../../../../experiments/minicpmo_kv_site/minicpmo_kv_patch.py) now replaces only the loaded Omni thinker's resampler KV projection.
