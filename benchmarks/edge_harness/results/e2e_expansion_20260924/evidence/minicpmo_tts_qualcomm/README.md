# MiniCPM-o 4.5 speech-head decode step across Qualcomm devices

This is a **single fixed-cache 20-layer speech-head step**, not the complete thinker, audio/vision encoders, vocoder or streaming MiniCPM-o pipeline. The retained Workbench source ONNX model `mn4gjjpvn` was recovered outside Git as `/home/zhout/project/edge_infer/models/minicpmo45_tts_step_L256_20260924.onnx` (776,341,465 bytes, SHA256 `78cf64804f11ad269ee4180da61588ccc5eefe2942773227345499756e4cc229`). It has FP32 hidden input `[1,1,768]`, rotary/mask inputs, 20 K/V cache pairs at length 256, and 6,562 logits plus 40 new-cache outputs. The historical export does not attest its exact checkpoint revision.

The [S25 historical inference](s25/inference_report.json) used dataset `d7gwxe3y2`; the [S24 historical inference](s24/inference_report.json) used `d7zn8rk57`. Downloaded inputs from both dataset IDs produced the same 44-array `.npz` SHA256 `65919ea1f351feec33c1415a3e3db76d60bc9c2beb3d49a72af75dcb418e83b4`. The retained fixture is outside Git under `/home/zhout/project/edge_infer/models/minicpmo45_tts_step_fixture_s25_20260924.npz`. ONNX Runtime 1.29 CPU produced a 41-output reference (SHA256 `902adcceadbe761d938ef2ade51cf953c8917ea1abfaee33a10c84e300c1bd96`), also outside Git.

The historical [S24](s24/compile_report.json) and [S25](s25/compile_report.json) FP16 QNN context-binary compiles and inference jobs succeeded. Against the **same original ONNX CPU fixture**, [S24](s24/audit_report.json) logits relative L2 was **0.3459%** and max K/V relative L2 **1.235%**; [S25](s25/audit_report.json) logits relative L2 was **0.3605%** and max K/V relative L2 **1.311%**. Both preserved the CPU top-1 speech token **1867** on this one synthetic step. The raw [S24](s24/device_output.npz) and [S25](s25/device_output.npz) arrays are retained. The [S24](s24/profile_report.json) and [S25](s25/profile_report.json) profiles each returned 100 fixed-cache 20-layer component samples, with nearest-rank p50/p95 **8.537/9.006 ms** and **7.197/7.615 ms**, respectively. All **1,029 execution-detail rows** in each profile were attributed to NPU. The service estimated-time fields were the sample minima (8.211/7.125 ms), not medians. Reported inference peak memory was 165,433,344/185,991,168 bytes. The [S24](s24/audit_report.json) and [S25](s25/audit_report.json) audits now bind numerical outputs and placement to the exact target/device; generated-audio quality and complete model state remain unverified.

New FP16 QNN DLC [SA8775P](sa8775p/compile_report.json), [Snapdragon X Elite](xelite/compile_report.json) and [RB3 Gen 2](rb3/compile_report.json) compiles passed from the same source. The X Elite [NPU-requested inference](xelite/inference_report.json) also returned all 41 finite tensors: its [audit](xelite/audit_report.json) found **0.3170% logits relative L2**, preserved CPU top-1 token **1867**, and measured maximum K/V relative L2 **1.221%**. The exact RB3 [FP16 QNN DLC inference](rb3/inference_report.json) **failed** while loading the graph with QnnModel_composeGraphsFromDlc: MODEL_GRAPH_ERROR, despite a successful compile. RB3 does not advertise FP16 HTP support in the device attributes; this failure constrains the tested artifact, not every RB3 path. An explicit [TFLite CPU fallback compile](rb3/cpu_fallback/compile_report.json) succeeded, producing target mnwv5d7wq; [same-fixture CPU-requested inference](rb3/cpu_fallback/inference_report.json) returned 41 finite tensors, preserved CPU top-1 token **1867**, and had logits relative L2 **1.26e-6** and maximum K/V relative L2 **1.58e-6** versus the original ONNX CPU fixture. The [CPU fallback profile](rb3/cpu_fallback/profile_report.json) returned 100 decode-step component samples at nearest-rank p50/p95 **59.518/71.347 ms**, with all **1,008 execution-detail rows on CPU**. The 59.007 ms estimated-time field is the sample minimum. Reported inference peak memory was 820,981,760 bytes. This is a numerical and placement-passing component fallback, not a full model request.
