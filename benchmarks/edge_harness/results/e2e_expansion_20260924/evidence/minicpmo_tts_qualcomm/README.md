# MiniCPM-o 4.5 speech-head decode step across Qualcomm devices

This is a **single fixed-cache 20-layer speech-head step**, not the complete thinker, audio/vision encoders, vocoder or streaming MiniCPM-o pipeline. The retained Workbench source ONNX model `mn4gjjpvn` was recovered outside Git as `/home/zhout/project/edge_infer/models/minicpmo45_tts_step_L256_20260924.onnx` (776,341,465 bytes, SHA256 `78cf64804f11ad269ee4180da61588ccc5eefe2942773227345499756e4cc229`). It has FP32 hidden input `[1,1,768]`, rotary/mask inputs, 20 K/V cache pairs at length 256, and 6,562 logits plus 40 new-cache outputs. The historical export does not attest its exact checkpoint revision.

The [S25 historical inference](s25/inference_report.json) used dataset `d7gwxe3y2`; the [S24 historical inference](s24/inference_report.json) used `d7zn8rk57`. Downloaded inputs from both dataset IDs produced the same 44-array `.npz` SHA256 `65919ea1f351feec33c1415a3e3db76d60bc9c2beb3d49a72af75dcb418e83b4`. The retained fixture is outside Git under `/home/zhout/project/edge_infer/models/minicpmo45_tts_step_fixture_s25_20260924.npz`. ONNX Runtime 1.29 CPU produced a 41-output reference (SHA256 `902adcceadbe761d938ef2ade51cf953c8917ea1abfaee33a10c84e300c1bd96`), also outside Git.

The historical [S24](s24/compile_report.json) and [S25](s25/compile_report.json) FP16 QNN context-binary compiles and inference jobs succeeded. Against the **same original ONNX CPU fixture**, [S24](s24/audit_report.json) logits relative L2 was **0.3459%** and max K/V relative L2 **1.235%**; [S25](s25/audit_report.json) logits relative L2 was **0.3605%** and max K/V relative L2 **1.311%**. Both preserved the CPU top-1 speech token **1867** on this one synthetic step. The raw [S24](s24/device_output.npz) and [S25](s25/device_output.npz) arrays are retained. These values are numerical component evidence, without a generated-audio quality threshold or actual NPU placement profile.

New FP16 QNN DLC [SA8775P](sa8775p/compile_report.json), [Snapdragon X Elite](xelite/compile_report.json) and [RB3 Gen 2](rb3/compile_report.json) compiles passed from the same source. Same-fixture NPU-requested inference jobs were [submitted for SA8775P](sa8775p/inference_submission.json), [X Elite](xelite/inference_submission.json) and [RB3](rb3/inference_submission.json), but were pending at this snapshot. A compile cannot establish device execution or numerical parity. The [collector](../../../../experiments/collect_aihub_component.py) retrieves terminal jobs, and the [auditor](../../../../experiments/audit_minicpmo_tts_qualcomm.py) pins hashes and checks all 41 output tensors.
