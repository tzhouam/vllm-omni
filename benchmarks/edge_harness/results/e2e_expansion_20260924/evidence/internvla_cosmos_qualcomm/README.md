# InternVLA Cosmos encoder across Qualcomm devices

This tests the **real Place_Markpen Cosmos CI8x8 image encoder component**, not the action policy or complete InternVLA. The [source export](../../../e2e_expansion_20260923/evidence/internvla_cosmos_amd_npu/README.md) pins the checkpoint, FP32 `[6,3,256,256]` input, `[6,16,32,32]` output, two CPU parity fixtures and the original external-data ONNX files. The external data were embedded into one 125,112,088-byte ONNX file outside Git at `/home/zhout/project/edge_infer/models/InternVLA-cosmos-onnx/cosmos_encoder_embedded.onnx` (SHA256 `656a5263f584851a1457ef6dcf60b995f7c67b056b3c90a4f33c814f7caf9ec9`). The embedded form retained reference-relative ONNX CPU L2 errors of `8.74e-7` and `2.29e-6` on ramp and pattern fixtures.

Workbench source model `mn4okj3rq` was [submitted for Galaxy S25 QNN DLC compilation](s25/compile_submission.json) as job `jpxl4d1jp`, with `default_graph_htp_precision=FLOAT16`. The [compile](s25/compile_report.json) succeeded and produced target model `mqkp12rxm`. [Same-fixture pattern inference](s25/inference_report.json) requesting NPU also succeeded. The [audit](s25/audit_report.json) found **0.0524% relative L2 / 65.61 dB SNR** versus the pinned source latent, with finite FP32 `[6,16,32,32]` output. This establishes numerical behavior on one synthetic encoder fixture; the [placement profile](s25/profile_report.json) attributed all 121 execution-detail rows to NPU. Its 100 six-frame component samples had nearest-rank p50/p95 49.665/51.382 ms (minimum 47.438 ms); reported inference peak memory was 158,232,576 bytes. The service reported first/warm load times of 20.996/0.178 s and corresponding peak memories of 679,317,504/279,449,600 bytes for this component job. The combined audit binds placement, numerical output and exact target/device. These exclude the action policy, data handoff, cold-load cost and sustained operation.

The same source model also [compiled to FP16 QNN DLC on Snapdragon X Elite CRD](xelite/compile_report.json), producing target `mmxj0w8kq` for Windows ARM. [Same-fixture NPU-requested inference](xelite/inference_report.json) on dataset `d26qo8p57` returned a finite FP32 `[6,16,32,32]` latent. Its [audit](xelite/audit_report.json) measured **0.0608% relative L2 / 64.32 dB SNR** versus the pinned source pattern, with cosine 0.999999815. The [placement profile](xelite/profile_report.json) returned 100 six-frame component samples at nearest-rank p50/p95 **82.939/83.837 ms**, with all **121 execution-detail rows on NPU**. The 82.446 ms estimated-time field is the sample minimum. Reported inference peak memory was 24,059,904 bytes and first-load peak 692,891,648 bytes. This is component evidence only; neither action quality nor a complete device-local policy was tested.

The same source also [compiled to FP16 QNN DLC on SA8775P ADP](sa8775p/compile_report.json), producing target mn750wz8m for Android. [Same-fixture NPU-requested inference](sa8775p/inference_report.json) using dataset d26qo8p57 returned a finite FP32 [6,16,32,32] latent. Its [audit](sa8775p/audit_report.json) measured **0.0613% relative L2 / 64.25 dB SNR** versus the pinned source pattern, with cosine 0.999999812. The [placement profile](sa8775p/profile_report.json) returned 100 six-frame component samples at nearest-rank p50/p95 **116.021/116.327 ms**, with all **121 execution-detail rows on NPU**. The 114.779 ms estimated-time field is the sample minimum. Reported inference peak memory was 116,924,416 bytes and first-load peak 659,845,120 bytes. No complete local policy follows.

The same source has exact-device [Galaxy S24 FP16 QNN DLC](s24/compile_report.json) and [RB3 Gen 2 ONNX CPU](rb3_cpu/compile_report.json) compiles. Same-fixture [S24 NPU-requested inference](s24/inference_report.json) returned a finite latent at **0.0613% relative L2 / 64.25 dB SNR** versus the pinned source pattern ([audit](s24/audit_report.json)). [RB3 CPU-requested inference](rb3_cpu/inference_report.json) returned a finite latent at **2.20e-6 relative L2 / 113.17 dB SNR** versus source ([audit](rb3_cpu/audit_report.json)). The [S24 placement profile](s24/profile_report.json) returned 100 six-frame component samples at nearest-rank p50/p95 **64.314/67.472 ms**, with all **121 execution-detail rows on NPU**. Reported inference peak memory was 309,661,696 bytes and first-load peak 712,884,224 bytes. The [RB3 placement profile](rb3_cpu/profile_report.json) returned **46** six-frame component samples at nearest-rank p50/p95 **13.018/13.053 s**, with all **590 execution-detail rows on CPU**; reported inference peak memory was 220,680,192 bytes. The [S24](s24/audit_report.json) and [RB3](rb3_cpu/audit_report.json) full audits bind numerical output, placement and exact target. These are encoder component checks; no complete policy was resident on either device.

The [generic collector](../../../../experiments/collect_aihub_component.py) preserves terminal jobs, and the [Cosmos auditor](../../../../experiments/audit_internvla_cosmos_qualcomm.py) checks source/fixture hashes, target/device/dataset identity, latent shape and finite numerical difference against the pinned source reference. Separate synthetic action-sensitivity checks injected the pinned source or hosted [S25](s25/action_sensitivity.json), [S24](s24/action_sensitivity.json), and [RB3](rb3_cpu/action_sensitivity.json) latents into the same real Place_Markpen policy on **local CPU**, with zero state/noise. The [reproducer](../../../../experiments/probe_internvla_hosted_latent_actions.py) returned finite action tensors of shape [1,50,32]; hosted-vs-source action relative L2 was **0.742% / 0.631% / 0.594%**, respectively. Repeating the source policy gave bitwise identical actions in each run. The S24/RB3 reports pin the imported current fork source, PyTorch 2.13.0+cpu, vLLM 0.28.0 and Transformers 5.14.1. The RB3 latent's near-exact encoder match did not imply action identity after the policy's bfloat16 path. These are numerical handoff experiments, not device-local policy or robot-task passes; no real-observation action tolerance is known.
